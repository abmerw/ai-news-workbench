数据源（默认读本站 data/ainews.json）
页面默认从同目录的 data/ainews.json 读取，由 GitHub Actions 每小时更新。这里可以填另一个公开、允许跨域读取的 JSON 地址来覆盖它（数组，或含 items 的对象），留空则用默认文件。
数据存储位置
本页数据保存在当前浏览器的 localStorage（key 前缀 wb_ainews_），离线可正常录入与查阅。云端数据表由每小时定时任务写入最新 AI 资讯，同时把最新批次内联进本页并重新发布——每次打开都会自动合并新资讯，你的阅读状态、备注与删除记录始终保留。
同步状态
导出 JSON 备份
把全部资讯导出为 JSON 文件，用于本地快照或迁移到其他设备。
导入恢复
支持本工作台导出的 JSON、纯数组，以及定时任务产出的简报 JSON；按标题与链接去重合并，无条数上限。
清空示例数据
只移除首次打开时预置的 5 条示例，你自己新增的内容不受影响。
清空全部数据
删除本机保存的所有资讯，操作不可恢复，需二次确认。
安装到手机桌面（本地使用）
用手机浏览器打开独立网址后点右侧按钮，按提示添加到主屏幕：独立图标、全屏打开、断网也能看，数据仍存在本机浏览器。不需要应用商店上架。
不知道某个功能怎么用？
长按页面上的任意按钮、标签或卡片（手机上按住约半秒，电脑上按住鼠标左键），会立刻弹出该功能的用法说明，松开也不会误触原来的操作。
关于自动更新
GitHub Actions 每小时抓取一次资讯源（量子位、雷锋网、钛媒体、IT之家），生成 data/ainews.json 并提交到本仓库，站点由 GitHub Pages 托管，全程不经过 WorkBuddy。抓取只做规则能可靠做到的事：标题、来源、链接、摘要、分类；拆不出步骤的条目不编流程图，卡片会降级显示要点。点「立即刷新」会真的重新拉取一次文件。你的阅读状态、备注和删除记录只在本机浏览器，不会写回仓库。
